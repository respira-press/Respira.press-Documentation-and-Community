## Overview

Connect Respira to WooCommerce by installing the WooCommerce add-on plugin, checking that your plan includes it, and confirming that your AI assistant can access [WooCommerce MCP tools](https://www.respira.press/tools/woocommerce).

<Callout kind="info">

Before you start, confirm that:

- Respira Core is installed and configured on your WordPress site. If not, follow the [Installation](/installation) guide first.
- The official WooCommerce plugin is installed, active, and connected to your store on the same site.

</Callout>

## Requirements

The WooCommerce integration works only when all of the following are true:

- **Respira Core plugin is active** on your WordPress site.
- **WooCommerce plugin is active** and your store is set up.
- **Your plan includes the WooCommerce add-on**, or you have subscribed to it. There is no free trial for the add-on.
- The Respira plugin on the site is **connected to your Respira account**. The add-on has no license key of its own and uses that connection.

Support for the WooCommerce add-on is included while the add-on is active. Email **word@respira.press** for help.

## Install the WooCommerce add-on

Use these steps to subscribe, install, and activate the WooCommerce integration.

<Steps>

<Step title="Subscribe to the WooCommerce add-on" icon="download">

Start your subscription so you can access updates and support for the WooCommerce integration.

- Studio and Founder plans include the add-on, so there is nothing to buy.
- On Maker and Builder, open [Billing](https://www.respira.press/dashboard/billing) in your dashboard and press **Add for €95/year**.

The Billing page then shows **WooCommerce add-on · Active**.

</Step>

<Step title="Download the WooCommerce add-on plugin" icon="download">

Download the latest version of the WooCommerce add-on as a ZIP file.

- Open [Downloads](https://www.respira.press/dashboard/downloads) in your dashboard and download the WooCommerce add-on ZIP. The download needs an active Respira plan and the add-on.

You should now have a ZIP file for the WooCommerce add-on on your computer.

</Step>

<Step title="Install and activate the plugin in WordPress" icon="package">

Add the WooCommerce add-on to your WordPress site like any other plugin.

- In WordPress admin, go to **Plugins → Add New**.
- Click **Upload Plugin**.
- Choose the WooCommerce add-on ZIP you downloaded.
- Click **Install Now**, then **Activate** once installation completes.

After activation, you should see WooCommerce settings available under the Respira menu in WordPress.

</Step>

<Step title="Let the add-on check your plan" icon="key">

There is no license key to paste. The add-on reads the licence of the Respira plugin on the same site and checks it with respira.press once a day. While it is not yet active it checks again every 10 minutes.

- Make sure the Respira plugin on this site is connected to your account.
- The add-on's own screen is in WordPress admin under **WooCommerce → Respira ARC**.

</Step>

<Step title="Verify WooCommerce tools are available" icon="check-circle">

Confirm that the MCP server detects WooCommerce and exposes the full set of tools.

<Callout kind="info">

Use this quick prompt in your AI assistant that is connected to Respira:

> What WooCommerce tools are available?

A successful setup returns the **104 WooCommerce tools**. If you see fewer tools or an error, check the Troubleshooting section below.

</Callout>

</Step>

</Steps>

## Troubleshooting and next steps

If WooCommerce tools do not appear or the add-on does not become active:

- Review the [Troubleshooting](/woocommerce/troubleshooting) guide for WooCommerce-specific fixes.
- Confirm that both **Respira Core** and **WooCommerce** plugins are active.
- Check that the [Billing](https://www.respira.press/dashboard/billing) page shows the WooCommerce add-on as active, and that the Respira plugin on this site is connected.

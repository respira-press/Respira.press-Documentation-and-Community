## What Respira Code is

Respira Code is an add-on for Respira for WordPress. Respira edits pages. Respira Code goes further: your AI agent can write a small application for your site, in PHP, SQL and scheduled jobs, and ship it without being able to take the site down or lose its data. These are called apps.

- **A crash guard.** A release that fails its checks never keeps serving. The previous release takes over.
- **A snapshot before every data change.** Guarded SQL and migrations take one first.
- **A kill switch that only you hold.** One switch turns every app and every key off, even when wp-admin is down.
- **The respira CLI.** `npx -y @respira/cli app deploy` and the other `app` commands, plus the Respira Code MCP tools.

The full guide is at [respira.press/docs/code](https://www.respira.press/docs/code). It covers the install steps, the commands, the safety rules and every limit.

## Who gets it

It needs the Respira plugin (9.3.10 or newer) on the site and a paid Respira plan. It is not available on a trial.

- **Price:** EUR 20 a month or EUR 158 a year.
- **Included at no extra cost** on yearly Builder 10, yearly Studio and the legacy Agency plan, while the 100 launch licences last. The number left is shown on the [pricing page](https://www.respira.press/pricing), on the [Respira Code page](https://www.respira.press/code) and on the Downloads page of your dashboard.
- **Not included** on Maker and Builder 5. They can add it.
- **Founder** licences have everything.

## Install

1. Open [Downloads](https://www.respira.press/dashboard/downloads) in your dashboard and press **Download Respira Code**.
2. In wp-admin, open **Plugins**, then **Add New Plugin**, then **Upload Plugin**. Choose the zip, press **Install Now**, then **Activate Plugin**.
3. Open **Respira Code** in the wp-admin menu and go through its three setup steps.

Only the site owner installs it and switches it on. An agent cannot do either.

## Tools Reference

Every plan includes 300+ tools (302 on 17 November 2026). The paid [WooCommerce add-on](/woocommerce/overview) adds 104 more, which makes 400+ with the add-on (406). Those two figures count each tool once, whether it is offered through the MCP server or as a WordPress Ability.

The [public tools catalog](https://www.respira.press/tools) lists more entries than that: 508 tools in 34 categories on 17 November 2026. It is longer because it also includes the tools that appear only where they apply:

- 54 ACF tools, only when Advanced Custom Fields is active
- 25 Bricks tools, only on Bricks
- 8 tools from the Elementor module: 7 only on Elementor, and `respira_add_stock_image`, which every site sees
- 11 Avada tools, only on Avada
- 6 Yoast SEO tools, only when Yoast SEO is active
- 4 YOOtheme Pro template tools, only on YOOtheme Pro
- 3 Blocksy tools, only on the Blocksy theme
- 10 Respira Code tools, only on a site with the Respira Code add-on

The catalog is counted from the code on every release, so it is the place to check the current numbers. This page follows the same categories. Tool names here use the `wordpress_` prefix, as the catalog does; an MCP client lists the same tools as `respira_*`.

## What one site sees

A site sees fewer tools than the catalog, because the server lists only the tools for the site's builder and plugins. A Gutenberg site without WooCommerce, ACF or a builder module sees the core tools only. Turning on the WooCommerce add-on, ACF or a builder module adds its tools. A tool switched off in Respira under Tools, or hidden by a key's profile, does not appear either. Ask your client for its tool list to see the exact number for a site.

## Other surfaces

- **The site's own MCP endpoint**, used by the claude.ai and ChatGPT connectors, names the tools `respira_wordpress_*`. A few tools exist only there and not on the npm server, among them the guarded update tools. They are listed further down this page.
- **WordPress Abilities**: the plugin registers 400 abilities, so browser AI can reach almost every tool.

## Tool Naming Convention

Core tools follow the pattern `respira_[action]_[resource]`. ACF tools are named `respira_acf_*` and WooCommerce tools `woocommerce_*`.

<Callout kind="info">
Starting in v5.2.0, the MCP server lists every core tool under its `respira_*` name (preferred). The same tool called with the `wordpress_*` prefix still works, and is deprecated. The `wordpress_*` names will be removed in a future major version. This page, most per-tool pages and the public catalog show the `wordpress_*` names, so `wordpress_list_pages` here is `respira_list_pages` in an MCP client.
</Callout>

- `list_*` - Get multiple items
- `get_*` / `read_*` - Get single item
- `create_*` - Create new item
- `update_*` - Modify existing item
- `delete_*` - Remove item
- `analyze_*` - Read-only analysis
- `check_*` - Quick validation

## FAQ

### How many tools does Respira have?

Every plan includes 300+ tools (302 on 17 November 2026), and 400+ with the WooCommerce add-on (406). The public catalog lists 508 entries in 34 categories, because it also counts the tools that appear only on a site that runs the Respira Code add-on, ACF, Bricks, Elementor, Avada, Yoast SEO, YOOtheme Pro or Blocksy. One site sees fewer than the catalog, depending on its builder and plugins. The [live tools catalog](https://www.respira.press/tools) is counted from the code on every release.

### What's the difference between read-only and write tools?

Read-only tools (like `wordpress_list_pages`, `wordpress_analyze_seo`) only retrieve information—they never modify your site. Write tools (like `wordpress_update_page`, `wordpress_delete_post`) can change content. Write operations use the duplicate-first workflow by default, so you review changes before they go live.

### Which tools are safe to use on production?

All analysis tools are completely safe as they're read-only. For write operations, Respira's duplicate-first workflow protects your live content. The AI creates a draft copy, you review it in WordPress Admin (Respira → Approve Edits), and only then does it replace the original. You can also use [wordpress_validate_security](/tools/other/validate-security) to check content before saving.

### Can I manage multiple sites with these tools?

Yes. Use [wordpress_switch_site](/tools/other/switch-site) to switch between configured WordPress sites during a session. Configure multiple sites in `~/.respira/config.json` and the AI can work across all of them.

### Do I need to remember all the tool names?

No. Your AI assistant knows all available tools and will choose the right one based on your natural language request. Just describe what you want ("update the homepage title", "list all pages", "analyze SEO") and the AI selects the appropriate tool.

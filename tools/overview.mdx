# Tools Reference

As of plugin 9.2.3 and MCP server 8.5.0 (npm `@respira/wordpress-mcp-server`), the MCP server lists **252 core tools, 356 with the WooCommerce add-on**. 91 more tools come from modules that list them where they apply:

- 54 ACF tools, only when Advanced Custom Fields is active
- 25 Bricks tools, only on Bricks
- 8 tools from the Elementor module: 7 only on Elementor, and `respira_add_stock_image`, which every site sees
- 4 YOOtheme Pro template tools, only on YOOtheme Pro

The [public tools catalog](https://www.respira.press/tools) counts all of them: 447 tools in 30 categories. It is counted from the code on every release, so it is the place to check the current numbers. This page follows the same categories. Tool names here use the `wordpress_` prefix, as the catalog does; an MCP client lists the same tools as `respira_*`.

## What one site sees

A site sees fewer tools than the catalog, because the server lists only the tools for the site's builder and plugins. Measured `tools/list` counts:

| Site | Tools listed |
|------|--------------|
| Core, on Gutenberg | 253 |
| Core, with ACF | 307 |
| With the WooCommerce add-on | 357 |
| YOOtheme Pro site | 257 |
| WooCommerce and ACF, on Elementor | 418 |
| WooCommerce and ACF, on Bricks | 436 (the most one site can see) |

## Other surfaces

- **The site's own MCP endpoint**, used by the claude.ai and ChatGPT connectors, lists 353 tools named `respira_wordpress_*`. 10 of them are only there. They are listed further down this page.
- **WordPress Abilities**: the plugin registers 360. Across the MCP server and the abilities that makes 366 distinct tools and abilities (360+), or 262 (260+) without the paid WooCommerce add-on.

## Tool Naming Convention

Core tools follow the pattern `respira_[action]_[resource]`. ACF tools are named `respira_acf_*` and WooCommerce tools `woocommerce_*`.

<Callout kind="info">
Starting in v5.2.0, the MCP server lists every core tool under its `respira_*` name (preferred). The same tool called with the `wordpress_*` prefix still works, and is deprecated. The `wordpress_*` names will be removed in a future major version. This page, most per-tool pages and the public catalog show the `wordpress_*` names, so `wordpress_list_pages` here is `respira_list_pages` in an MCP client.
</Callout>

- `list_*` - Get multiple items
- `get_*` / `read_*` - Get single item
- `create_*` - Create new item
- `update_*` - Modify existing item
- `delete_*` - Remove item
- `analyze_*` - Read-only analysis
- `check_*` - Quick validation

## FAQ

### How many tools does Respira have?

As of plugin 9.2.3 and MCP server 8.5.0: 252 core tools, 356 with the WooCommerce add-on. 91 more come from modules listed where they apply (ACF, Bricks, Elementor and YOOtheme Pro), so the public catalog counts 447 tools in 30 categories. One site sees between 253 and 436, depending on its builder and plugins. The plugin also registers 360 WordPress Abilities. The [live tools catalog](https://www.respira.press/tools) has the current numbers.

### What's the difference between read-only and write tools?

Read-only tools (like `wordpress_list_pages`, `wordpress_analyze_seo`) only retrieve information—they never modify your site. Write tools (like `wordpress_update_page`, `wordpress_delete_post`) can change content. Write operations use the duplicate-first workflow by default, so you review changes before they go live.

### Which tools are safe to use on production?

All analysis tools are completely safe as they're read-only. For write operations, Respira's duplicate-first workflow protects your live content. The AI creates a draft copy, you review it in WordPress Admin (Respira → Approve Edits), and only then does it replace the original. You can also use [wordpress_validate_security](/tools/other/validate-security) to check content before saving.

### Can I manage multiple sites with these tools?

Yes. Use [wordpress_switch_site](/tools/other/switch-site) to switch between configured WordPress sites during a session. Configure multiple sites in `~/.respira/config.json` and the AI can work across all of them.

### Do I need to remember all the tool names?

No. Your AI assistant knows all available tools and will choose the right one based on your natural language request. Just describe what you want ("update the homepage title", "list all pages", "analyze SEO") and the AI selects the appropriate tool.

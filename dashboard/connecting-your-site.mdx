# Connecting Your Site

Linking a site takes one sign-in from the plugin: you press a button in wp-admin, confirm on respira.press, and land back in wp-admin with the site linked. No keys to copy.

> **Connecting Claude Desktop or claude.ai?** That uses a separate browser sign-in flow you start from inside the AI client, not this dashboard handshake. See [Connect Claude Desktop (OAuth)](/connect-claude-desktop-oauth).

## Prerequisites

- The latest Respira for WordPress plugin on the site (the steps below describe it; the Connect a site page has the download)
- A Respira account at [respira.press](https://www.respira.press) (free trial works)
- Signed in to that account in the same browser you use for wp-admin

If the site runs an older Respira, update it first from **Plugins** in wp-admin.

## Step by step

### 1. Start on respira.press

On the [Sites page](https://www.respira.press/dashboard/sites), press **Connect a site**. The page has the plugin download, your licence key and a live check that watches for the new site. Keep it open.

### 2. Install the plugin

In the new site's wp-admin go to **Plugins → Add New → Upload Plugin**, choose the file you downloaded, then **Activate**. A **Respira** menu appears in the sidebar.

### 3. Link the site

Open **Respira → Setup** and press **link this site to respira.press**. A respira.press page opens; sign in if you are not already, and confirm. You land back in wp-admin with your licence key saved and the site linked.

### 4. Check it on respira.press

The Connect a site page notices the new site within a few seconds and takes you back to Sites, where it shows as *Token ready*. From there, [MCP Setup](https://www.respira.press/dashboard/mcp) connects the site to your AI app.

## If linking does not work

| What you see | Likely cause | What to do |
| --- | --- | --- |
| The respira.press sign-in page never loads | A firewall, a security plugin or a locked-down wp-admin blocks the redirect | Use the licence key instead (below) |
| You land on the respira.press login page | You are not signed in to your Respira account in this browser | Sign in, then press **link this site to respira.press** again |
| The button reads **Upgrade to add a site** on respira.press | Every site slot on your plan is in use | Remove a site you no longer use from Sites, or move to a larger plan under Billing |
| The site never appears on the Connect a site page | The plugin is not active, or the key does not match | Check **Plugins** in wp-admin; paste the key with the Copy button to avoid stray spaces |

Still nothing after a minute? Email [word@respira.press](mailto:word@respira.press) with the site URL.

### Linking with the licence key instead

If the sign-in cannot run, open **Respira → Setup** in wp-admin, choose **paste a license key**, and paste the key from the Connect a site page on respira.press (use its **Copy key** button). The site links the same way.

## Security notes

- An agent reaches a site with that site's own key, made in [MCP Setup](https://www.respira.press/dashboard/mcp). A key opens that one site only. Treat it like a password: never commit it to git or paste it in a public chat.
- Make a new key at any time in MCP Setup (**Regenerate key** in the site's menu); the old one stops working at once. **Revoke key** removes it.
- Removing a site from Sites revokes its key and frees its slot. The plugin stays installed on the WordPress site, and **Respira → Setup** links it again.

## What happens next

Once your site is connected:

- It appears in your **MCP Setup** config exports (`/dashboard/mcp` includes every connected site automatically)
- Per-site one-click install buttons are unlocked on the *Connected Sites* table
- Every change an agent makes is logged on the site, under **Respira → Activity** and **Respira → Audit Log** in wp-admin
- Usage from this site contributes to the **My Activity (30d)** strip on your dashboard home

Next up: head to [MCP Setup](/installation#step-3-set-up-mcp) to plug the site into your AI assistant of choice.
